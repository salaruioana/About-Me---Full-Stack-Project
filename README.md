# Personal Website

An interactive full-stack website centered around my personal profile, developed as a university project. The application combines dynamic web content with client-side data management, authentication, and interactive visual elements.

## Technologies

- **HTML5**
- **CSS3** — Flexbox, media queries, pseudo-classes and pseudo-elements
- **JavaScript**
- **XML / JSON**
- **SVG**
- **Canvas**
- **Web Workers**
- **localStorage / IndexedDB**

## Features

- Interactive personal profile website
- Responsive user interface
- Dynamic content loaded from XML and JSON
- User authentication and registration
- Interactive SVG graphics and Canvas elements
- Client-side data storage using localStorage and IndexedDB
- Background processing using Web Workers
